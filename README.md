# Java-Script
JavaScript is a single threaded scripting language. It is a versatile programming language primarily used for adding interactivity and dynamic features to your web applications. It is executed line by line. It can be used for backend also.

# JS Engine
Every web browser has it's own JS Engine. JS Engine is a software that converts JS code into Abstract Syntax Tree and then an interprater is used to convert it ABS Tree into byte code.

## List of JS Engines
1. Chrome - V8 Engine
2. Edge - Chakra
3. Mozilla Firefox - Spider Monkey

# NodeJS
It is an open-source, cross platform JavaScript runtime environment that allows developers to run JavaScript code outside of a web browser. It is build on chrome V8 engine. NodeJS enables the use of JavaScript for server-side scripting.

# Deep copy v/s Shallow copy
## Shallow copy
A shallow copy occurs when you copy the reference of an object into a new variable. Only the top properties are copied, while nested objects or arrays still reference the original memory location. Changes made in one object affect the other.

## Deep copy
A deep copy creates a completely independent copy of the object, including all nested objects or arrays. Changes made in one object do not affect the other.
